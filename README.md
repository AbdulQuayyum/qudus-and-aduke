# Qudus and Aduke First Year — Anniversary Site

A lightweight mobile-first anniversary microsite built with HTML, Tailwind utility classes, custom CSS, and vanilla JavaScript.

## Current story flow

1. **OUR FIRST YEAR** opening artwork
2. Private 8-digit date/code entry, displayed only as hearts
3. Editable HTML anniversary letter
4. Memories
5. Song section
6. Final message

## Private code

`05102025`

The entered digits are never rendered on screen; only heart indicators fill as digits are entered.

## Music

There is no local or remote background-audio system in this build. The music section uses only the Spotify embed for **Perfect — Ed Sheeran** plus the direct Spotify track link.

## Colour scheme

- Warm ivory background: `#F8F5EF`
- Ink / near-black: `#161616`
- Soft black: `#1F1F1F`
- Deep wine red accent: `#9D2E2E`
- Warm paper/tan: `#C4AA80`
- Muted taupe: `#7B746D`

The visual direction is editorial, scrapbook-like, warm, romantic, and understated rather than bright pink.
